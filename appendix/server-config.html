Cấu hình server (CSDL giải mã)

Giải mã files/db.sqlite3 (SQLCipher 4, mật khẩu = literal trong SQLiteDatabase..cctor, trùng Crypt.key) bằng tools/gd_gh_db.py. Bảng config chứa cấu hình server gửi cho tài khoản, tức các giá trị mà mã client không có. Nguồn: BlueStacks 5, tài khoản thử được nâng lên cấp 52 (để server gửi cả cấu hình của người chơi cấp cao), kéo lúc 06/10/2026 18:30; cấu hình sự kiện đã trả về đúng giá trị server sau khi thử. Mọi bảng: facts/runtime/db/levelspoof_final/tables/*.json; cấu hình server đầy đủ: facts/runtime/db/levelspoof_final/server_config.json.

Đây là cấu hình của một tài khoản tại một thời điểm; server có thể gửi khác theo cấp, nhóm người chơi, ngày.
