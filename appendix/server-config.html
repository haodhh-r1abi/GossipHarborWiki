Cấu hình server (CSDL giải mã)

Giải mã files/db.sqlite3 (SQLCipher 4, mật khẩu = literal trong SQLiteDatabase..cctor, trùng Crypt.key) bằng tools/gd_gh_db.py. Bảng config chứa cấu hình server gửi cho tài khoản, tức các giá trị mà mã client không có. Nguồn: BlueStacks 5, tài khoản cấp 5, kéo lúc 06/10/2026 17:00. Mọi bảng: facts/runtime/db/bluestacks_lv5/tables/*.json; cấu hình server đầy đủ: facts/runtime/db/bluestacks_lv5/server_config.json.

Đây là cấu hình của một tài khoản tại một thời điểm; server có thể gửi khác theo cấp, nhóm người chơi, ngày.
