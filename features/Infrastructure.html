Mô tả

  • Gossip Harbor là client Unity IL2CPP mỏng: phần C# lo khởi động, tải tài nguyên, mạng và lưu trữ; toàn bộ logic game chạy bằng Lua (XLua) tải về dạng hotfix từ CDN.
  • Khởi động đi qua 12 LoadingStage (init → privacyPolicy → sso → login → cdn → fileCfg → sync → checkRes → scene → loadview → basesceneview → finish).
  • Addressables lấy catalog từ https://diary.cdn.mergesigma.com/hotfix/<version>/android/ (dự phòng diary.cdn.ak.mergesigma.com), kiểm tra hash, tải bundle Lua cập nhật (contentupdate_assets_luadefault) và tài nguyên theo label, tải ngầm nội dung sự kiện sau khi vào game.
  • Giao tiếp server qua thư viện native NetLib (HTTP/UDP, ApiServer request kèm userId + serverTime, message id), cấu hình URL từ UrlConfig.
  • Dữ liệu người chơi và config server lưu trong SQLite mã hóa (SQLCipher) trên bộ nhớ ngoài.

Còn thiếu / chưa xác minh

📌 Endpoint API server và giao thức NetLib nằm trong libnetlib.so/Lua — không ghi lại
📌 Script Lua và CSDL được mã hóa — không giải mã
📌 Chưa kiểm tra catalog/bundle có được xác minh hash/chữ ký ngoài CRC Addressables hay không

Mở khóa & điểm vào

Luôn chạy.

Điểm vào:

  • Khởi động app
  • Quay lại từ nền (ApplicationWillEnterForeground → GameModel:Login lại)
  • Hộp thoại tải tài nguyên / lỗi mạng / buộc khởi động lại

Cách hoạt động

  1. ApplicationManager.Start → InitOrderly: PreInitView (thanh tiến độ, lỗi mạng Retry/Exit) → NetworkManager.CheckDomainsStatus chọn domain CDN ưu tiên (OnCheckCDNConnection, phát hiện mạng yếu/proxy) → AddressableManager.Init: URLTransfer thay placeholder 'https://runtimeurl' bằng URL hotfix theo version (GetHotfixUrlWithVersion, có retry), đọc catalog local trong APK (aa/settings.json, aa/catalog.json), tải catalog_<ver>.hash/.json từ CDN (retry checkHashRetryTimes/updateCatalogRetryTimes), TryHotfix tải bundle Lua cập nhật → LuaManager.Initialize(luaCodeMap)/StartLua (nạp code từ bundle; USE_REMOTE_CODE; LoadCDNFile) → Lua điều khiển các stage sso/login/cdn/fileCfg/sync/checkRes/scene/loadview → EnterGame ('enter game True') → với người chơi mới PlayCGForNewUser → tải ngầm nội dung sự kiện (muteDownloadQueue, maxMuteDownloadCnt).
  2. Khi phát hiện hotfix mới lúc đang chạy: CheckRemoteHotfixRestart → buộc khởi động lại (ForceRestartWindowWithCanvas).
  3. Lỗi tải SSL/mạng được ghi log và thử lại hoặc đổi CDN.
  4. Lưu dữ liệu: SQLiteHelper (SQLCipher) + PlayerPrefs (metadata bảng: TableModified_*, TableHasDataNew_*, LastSerializationTimestamp_*); đồng bộ server qua SyncModel (checkUpload theo chu kỳ, OnLoginFinished so syncTime).
